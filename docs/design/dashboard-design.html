  • IBM Plex Sans — labels, controls, tables.
  • IBM Plex Mono — every figure, tabular, -0.01em tracked.

Value changes cross-fade colour over 420 ms and never animate size or position. Under prefers-reduced-motion every transition and the connection pulse are switched off.

Rationale

The desk's output is an argument, not a number, so the page is built as a document with an instrument rail on top rather than as a grid of cards. One thin sticky rail answers the first question — alive, which book, kill switch, next cycle, price and how old it is — in a single line that never moves. Below it the page splits asymmetrically: the agent's note occupies the wide column and is the only surface lifted off the ground, set in a reading serif at 17.5 px so the reasoning is read rather than skimmed, with "what would change my mind" as a numbered list because those conditions genuinely are ranked triggers. The money column is narrower and quieter, all figures monospaced and tabular, because it is checked rather than read. Everything else — engines, history, caps — is separated by hairlines and space instead of borders, which keeps the card weight for the one thing that deserves it. Colour is rationed: a single indigo accent for anything interactive, green and red reserved strictly for direction and P&L, amber for degradation, and vermilion used for nothing except REAL money, so the mode can never be mistaken for a chart colour. Nothing on the page changes size when data arrives; only colour moves.
